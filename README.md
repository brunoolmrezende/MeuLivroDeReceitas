## Sobre o Projeto

Bem-vindo ao **MyRecipeBook**, uma aplicação para armazenar e gerenciar suas receitas favoritas!

Este projeto foi desenvolvido para proporcionar uma experiência prática e eficiente para quem adora cozinhar e compartilhar receitas. A API foi construída com **.NET 8** e segue boas práticas de desenvolvimento, garantindo escalabilidade, segurança e qualidade de código.

### Tecnologias Utilizadas
Backend
**C# e .NET 8** – Desenvolvimento da API RESTful

**Entity Framework Core** – ORM para acesso ao banco de dados

MySQL – Banco de dados para armazenamento de receitas e usuários

**FluentValidation** – Validação de dados da aplicação

**JWT & Refresh Token** – Implementação de autenticação segura

AutoMapper – Mapeamento de DTOs e entidades

Injeção de Dependências – Arquitetura desacoplada e testável

Arquitetura & Boas Práticas
**Domain-Driven Design (DDD)** – Organização modular do código

Princípios **SOLID** – Código limpo e sustentável

**Clean Architecture** – Separação clara de responsabilidades

Segurança
**Autenticação JWT + Refresh Token** – Tokens seguros para login e renovação de sessão

**Criptografia de Senhas** – Proteção de credenciais com hashing seguro

Qualidade
**SonarCloud** – Análise estática do código para manter alta qualidade

**Testes de Unidade & Integração** – Cobertura de código confiável

### Funcionalidades
✅ **Cadastro de Usuários** – Registre-se com nome, e-mail e senha, com validações robustas

✅ **Gerenciamento de Receitas** – Criação, edição, exclusão e busca de receitas

✅ **Integração com o ChatGPT** – geração de receitas a partir de ingredientes fornecidos. 

✅ **Autenticação Segura** – Login com JWT e renovação via Refresh Token

✅ **Login com Google** – Integração para autenticação via conta Google (em desenvolvimento)

✅ **Upload de Imagens** – Adicione fotos às suas receitas

✅ **Mensageria** – Uso de mensageria (Service Bus) para gerenciar a exclusão de contas
